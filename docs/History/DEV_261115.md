# 영문 문서 원문 보존 1차 기록 (2026-11-15)

기획: [PLAN_261115_ENGLISH_CHUNKING.md](../Plan/PLAN_261115_ENGLISH_CHUNKING.md)의 1차(P0, E1~E4). 브랜치 `dev`.
한국어 문서 경로는 바꾸지 않았다. 바뀐 것은 LLM 프롬프트에 추가한 "원문 언어 유지" 한 줄뿐이다.

## 변경 내용

### 언어 판별 (E1)

- 새 모듈 `ingestion/language.py`의 `detect_language(texts)`를 추가했다. 반환값은 `{language, hangul_ratio, letters}`다.
  - 한글/(한글+라틴) 비율이 0.05 미만이고 글자 수가 200자 이상이면 `en`, 나머지는 `ko`로 판정한다.
  - 기준을 넘지 못하거나 글자 수가 적으면 기존 동작인 `ko`로 둔다.
  - 한국어 문서에 영문 용어가 섞여 있어도 `ko`다.
- `pipeline.py`에서 블록을 추출한 직후 한 번 판별하고, 결과를 로그로 남긴다(`Source language: en (hangul_ratio=…)`).
- 청크 metadata(JSON)에 다음 값을 기록한다. DB 스키마는 바꾸지 않았다.
  - `source_language`
  - `chunk_policy`(`ko-v1` / `en-v1`)
  - `fallback_reason`(폴백한 청크만)

### 영문 LLM 청킹 프롬프트 (E2)

- `llm_chunker.py`에 영문 프롬프트를 추가했다: `SYSTEM_PROMPT_EN`(PDF), `DOCX_SYSTEM_PROMPT_EN`, `USER_TEMPLATE_EN`.
  - `select_prompts(language, docx)`가 언어에 맞는 프롬프트를 고른다.
- 영문 프롬프트의 최우선 규칙은 `<language_rules>`다.
  - 번역하지 않는다.
  - 수치·단위·인용·고유명사·URL·코드를 그대로 보존한다.
  - 노이즈만 고치고 요약하거나 내용을 빼지 않는다.
- 영문 프롬프트의 나머지 규칙:
  - 노이즈 교정: 줄 끝 하이픈과 합자를 정리하고, `arXiv:… [cs.CL]` 사이드바 스탬프를 지운다.
  - 영문 제목은 다음 청크의 첫 줄로 붙인다.
  - 청크가 연결어(`However`, `Therefore` 등)로 끝나지 않게 한다.
  - 표는 영문 산문으로 바꾸되 행과 열의 관계를 보존한다.
  - `section_title`은 영문으로 쓴다.
- 기존 입출력 규약은 그대로다: CTX/NEW 블록, JSON 배열, 200~800자, `[표]` 마커.
  - `[표]`는 파서가 넣는 구조 표식이라 영문 문서에서도 그대로 둔다.
- 한국어 PDF·DOCX 프롬프트에는 `<role>`에 "원문 언어를 유지하세요. 영문 용어·인용·문장은 번역하지 말고 원문 그대로 둡니다." 한 줄만 추가했다.

### LLM 출력 사후 검증 (E3)

- `find_translated_chunks()`는 원문 블록이 영문(한글 비율 0.05 미만)인 청크만 검사한다. `[표]` 마커는 계산에서 뺀다.
  - 출력 `text`나 `section_title`의 한글 비율이 원문보다 0.05 이상 높으면 번역으로 본다.
- `_process_batch()`는 `en` 배치에서 번역이 감지되면 한 번 다시 요청한다.
  - 그래도 번역되면 원문 블록으로 폴백하고 `fallback_reason="translated"`를 남긴다.
  - 재시도 횟수는 `llm_retries`로 남긴다.
- 기존 폴백에도 사유를 붙였다: JSON 파싱 실패는 `json_parse`, 호출 오류는 `error`.
  - 폴백 청크 수는 청킹 완료 로그에 함께 찍는다.
  - 429(quota) 오류는 기존처럼 즉시 중단한다.

### 영문 섹션 제목 감지 (E4, rule 경로)

- `detect_heading`, `detect_section_level`, `build_sections`에 `language` 인자를 추가했다. 기본값은 `"ko"`이고, `ko`일 때는 기존 규칙만 쓴다.
- `en`에서 제목으로 인식하는 것:
  - 번호 제목: `1 Introduction`(레벨 1), `3.1 …`(레벨 2), `3.2.1 …`(레벨 3), `A.2 …`
  - `Appendix A`
  - 이름 제목: `Abstract`, `References`, `Conclusion` 등
- 제목으로 보지 않는 것:
  - 마침표나 쉼표로 끝나는 줄
  - 13단어 이상인 줄
  - `arXiv:… [cs.CL]` 같은 사이드바 스탬프
- `ingest_with_rule_chunking`, `ingest_with_llm_chunking`에 `language` 인자를 추가했다. 청크에는 `source_language`가 실린다.

## 남은 일
