# 개발 환경·모델·프론트 변경 기록 (2026-11-09)

## 개발 환경과 Next.js

- Python 3.12 가상환경과 프론트 npm 의존성을 lock 파일 기준으로 구성했다.
- Vite 진입점을 Next.js 16.4.5 App Router로 전환했다.
- 기존 탭의 상태 유지 방식과 FastAPI API 경로를 유지한다.
- 로컬과 Docker 프론트는 3000 포트, 백엔드는 8000 포트를 사용한다.
- API_BASE는 상대 경로이며 Next.js rewrites가 백엔드로 연결한다.
- Docker 프론트는 standalone 출력과 정적 파일을 포함한다.
- 루트 .env는 백엔드에만 사용하며 프론트에 API 키를 복사하지 않는다.
- 실제 Docker 빌드·기동과 원격 배포는 미검증이다.

## 모델 변경

| 작업 | 모델 |
| --- | --- |
| QA 생성 | Gemini 3.8 Flash (기본), GPT-6 Luna |
| Judge | Gemini 3.7 Flash, GPT-5.6 Luna (기본) |
| 청킹·태깅·계층·도메인 분석 | Gemini 2.5 Flash |
| 임베딩 | Gemini Embedding 2, 1536차원 유지 |

Claude는 UI 선택에서 보류하고 기존 설정은 호환을 위해 남겼다.
중앙 설정에서 비용을 읽도록 변경했으며 Gemini 도입 가격은 연말 전에 재검토해야 한다.
현재 API 키의 모델 메타데이터 접근과 합성 문장 기반 생성·Judge 호출을 확인했다.

Gemini Judge는 생성자의 temperature=None 검증 오류와 텍스트 블록 목록 응답을
처리하도록 보완했다. Judge 응답 파싱 회귀 테스트 2개를 통과했다.

## 모델 선택 UI

- 모델 목록·기본값을 frontend/src/lib/models.ts에 모았다.
- ModelSelect는 둥근 트리거·메뉴·옵션, 기본 모델 배지와 선택 체크를 표시한다.
- 브라우저 기본 펼침 메뉴 대신 combobox/listbox를 사용한다.
- label과 도움말을 연결하고 방향키·Home/End·Enter/Space·Escape·Tab을 처리한다.
- 바깥 클릭으로 닫히며 선택 후 포커스를 복원한다.
- 생성·평가 진행 중에는 모델 선택을 잠근다.
- 좁은 화면은 한 열로 표시한다.

타입 검사와 DOM 상호작용 검증을 통과했다. 브라우저 스크린샷·직접 조작 검증은
현재 시스템 라이브러리 누락으로 수행하지 못했다.
